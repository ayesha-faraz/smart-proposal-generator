# User Journey

1. The user opens Propel and logs in or registers.
2. The user enters business and client details.
3. The user fills project context: audience, current situation, main goal, competitors, service, budget, timeline, tone, urgency, and language.
4. Propel generates a structured proposal preview.
5. The user reviews scope, investment, positioning, and next steps.
6. The user downloads a PDF to send to the client.
