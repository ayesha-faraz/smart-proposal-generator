# Competitor Analysis

| Alternative | Strength | Gap Propel Targets |
| --- | --- | --- |
| Generic document templates | Fast starting point | Still requires manual writing and formatting |
| Proposal software | Strong document management | Often heavy for early agency workflows |
| AI chat tools | Flexible generation | Lacks a focused proposal workflow and reusable structure |
| Freelance marketplaces | Lead and proposal exchange | Proposals are tied to marketplace rules and profiles |

Propel's angle is a focused agency-client operating workflow: brief capture, proposal generation, scoring, matching, and future deal-room tools.
