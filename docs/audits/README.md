# Audit Evidence

This folder stores test, accessibility, and Lighthouse evidence for GitHub review.

Expected files after validation:

- `test-latest.txt`: output from `npm test`
- `a11y-latest.txt`: output from `npm run audit:a11y`
- `lighthouse-local.report.html`: local production-preview Lighthouse report
- `lighthouse-local.report.json`: machine-readable Lighthouse report
